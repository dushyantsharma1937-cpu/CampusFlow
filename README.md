# CampusFlow

A Java-based Campus Management System built using Object-Oriented Programming (OOP) concepts.

## About the Project

CampusFlow aims to simplify campus activities by providing a centralized platform for students, faculty, and administrators.

## User Roles

- **Student:** View courses, attendance, assignments, and campus events.
- **Faculty:** Manage courses, attendance, and assignments.
- **Admin:** Manage students, faculty, courses, and campus events.

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Java Collections Framework

A Java-based Campus Management System built using Object-Oriented Programming (OOP) principles.

## Project Overview

CampusFlow is a console-based application designed to manage campus activities for three types of users:

- **Student:** View profile, courses, attendance, assignments, events and notifications.
- **Faculty:** Manage courses, attendance, assignments and announcements.
- **Admin:** Manage students, faculty, courses, events and reports.

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Java Collections Framework
- Git and GitHub
